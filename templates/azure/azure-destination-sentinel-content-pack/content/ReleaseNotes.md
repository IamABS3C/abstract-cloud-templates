# Abstract Security solution — release notes

| Version | Date | Notes |
| --- | --- | --- |
| 3.6.0 | 2026-09-27 | **Content reads the table Abstract actually fills.** The Abstract Azure Sentinel Destination sends each ACS event with its own top-level keys, so the Sentinel Destination template now creates one column per top-level key (nested objects as dynamic) and a DCR transformation that sets TimeGenerated and stores the reserved id/type keys as acs_id/acs_type. The ASIM parser, both analytics rules, the workbooks, the connector query and the Copilot skill read that shape and the older wrapped AbstractEvent shape; every query was run against both on a live workspace. `seed_sentinel.py` sends events the way the integration does. |
| 3.5.0 | 2026-07-05 | **Total comparison + live API integration.** Rewrote the Competitive & TCO workbook into a detailed, tier-aware tool: Sentinel tier pricing (Analytics $4.30 / Basic $0.50 / data-lake $0.05), **raw→enriched/aggregated reduction measured from `aggregation_count`** (live 34:1), incidents/MTTR/**MTTD** (SIEM detect-lag vs in-stream), detections + **live MITRE** from insights, enrichment coverage, and a pipeline-control panel (tune-at-source filters + detect-in-stream matrix). Added a **multi-endpoint API-sync connector** (`connector/abstract-api-sync.json`) that pulls Insights, tune-at-source filters, pipeline IO metrics (SOURCE/DESTINATION), and detection-effectiveness into Sentinel tables (endpoints confirmed against the Abstract API). Added a runnable **comparison Notebook** (`notebooks/abstract-vs-sentinel-comparison.ipynb`). Live-validated against the tenant: 34 insights, 3 tune-at-source filters, 473 ACS fields. |
| 3.4.0 | 2026-07-01 | **Sales & evaluation power-up.** Added a **Competitive & TCO Command Center** workbook (cost/TCO from Usage, detection coverage, insights-vs-alerts fidelity, MTTR/analyst-time, a 17-row capability gap matrix, and an augment→optimize→rebalance migration ladder — data panels live, comparative panels parameterized). Added an **Abstract Insights API pull connector** (Logic App → `AbstractInsights_CL`) so the comparison works even when Sentinel isn't the Abstract destination. Added a **packaged integration profile** (`solution/integration-profile/`, machine-readable JSON + README) and a **branded interactive HTML sales leave-behind** with a live savings calculator (`solution/sales/`). Bolder official-mark branding on the connector tile + Content Hub. |
| 3.3.0 | 2026-06-30 | Fully built-out, self-contained deployable package. `mainTemplate.json` now embeds **everything**: connector tile, ASIM parser, **2 analytics rules** (high/critical + brute-force success), **2 hunting queries** (rare product, high-risk identities), pipeline-overview workbook, and **3 SOAR playbooks** (enrich, verdict, tune-at-source) as nested deployments — with linked `metadata` and matching `contentPackages` dependencies. Branding switched to the **official Abstract mark** (self-contained SVG data-URI; no external image host). Install wizard collects optional Abstract API credentials for the playbooks. |
| 3.2.0 | 2026-06-17 | Initial Microsoft Sentinel Content Hub solution package: data connector tile, ASIM parser, 1 analytics rule (+1 ARM example), 2 hunting queries, pipeline-overview workbook, 2 SOAR playbooks, Security Copilot plugin + KQL skills + agent, and an Abstract MCP server. Lab/experimental — validate with the Microsoft Sentinel solution packaging/validation tooling before Content Hub submission. |
